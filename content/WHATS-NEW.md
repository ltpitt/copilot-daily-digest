## This Week (Last 7 Days)

### [Enterprise Live Migrations from Azure DevOps generally available](https://github.blog/changelog/2026-11-19-enterprise-live-migrations-from-azure-devops-generally-available)
*Nov 19, 2026*

Enterprise Live Migrations (ELM) from Azure DevOps Services to GitHub Enterprise Cloud with data residency is now generally available. You can move your repositories while your teams keep working, then cut over on your schedule. Manage migrations through the portal or CLI: Choose a guided experience in the Azure DevOps portal or script your migrations with the Azure DevOps CLI.

### [Improvements on the pull request overview in public preview](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview)
*Nov 19, 2026*

Your feedback has helped improve the new pull request Overview page since its November 5, 2026 public preview. Failed optional checks no longer make mergeable pull requests appear blocked. Previously missing merge requirements now show what needs attention.

### [Red Hat Enterprise Linux runner images now generally available](https://github.blog/changelog/2026-11-19-red-hat-enterprise-linux-runner-images-now-generally-available)
*Nov 19, 2026*

Red Hat Enterprise Linux (RHEL) 9 and RHEL 10 images for GitHub-hosted larger runners are now generally available. Originally introduced in public preview in June 2026 in partnership with Red Hat, these images are now fully supported for production workflows in GitHub Actions.

### [Connect Supabase, Box, Calendly, and more to Copilot](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot)
*Nov 18, 2026*

You can now connect eight more services to Copilot using GitHub-verified MCP servers, or connectors, available in public preview. They join more than 25 services you can already connect, like Slack, Figma, and Sentry. To see the full list, open Customize in the Copilot app or browse the Copilot customization page.

### [Gemini 4 Neon in GitHub Copilot](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot)
*Nov 18, 2026*

Gemini 4 Neon is now generally available in GitHub Copilot. It is designed for agentic coding, multistep tool use, and knowledge work. According to Google, Gemini 4 Neon delivers quality close to Gemini 4 Carbon at a lower token cost per task.

## Last 30 Days

### [Wait for pull request events with GitHub CLI](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli)
*Nov 18, 2026*

GitHub CLI now supports GitHub Event Streams. With gh v2.105.0, you and your agents can wait for a pull request to change with a single command instead of polling it in a loop. Run gh event listen with a pull request URL and the events you care about, such as a submitted review.

### [Customize GitHub Copilot for your team](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team)
*Nov 18, 2026*

You can now share the GitHub Copilot plugins your team relies on without asking every member to repeat the same setup. Team customizations are generally available for organization teams. Team maintainers and organization owners can select approved Agent Plugins as team defaults.

### [How we optimize GitHub Copilot for every new model](https://www.youtube.com/watch?v=JSC8eVojIWY)
*Nov 18, 2026*

How do you ship a coding agent that works smoothly across OpenAI, Claude, Gemini, and whatever model drops next week? You build a harness.

### [Copilot code review: Adaptive effort, secret detection, and more](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more)
*Nov 17, 2026*

GitHub Copilot code review now helps you catch more issues earlier, with less effort. Adaptive matches review depth to each pull request, so routine changes get a quick pass and risky changes get a deeper look. Reviews can also draw on related repositories and flag exposed secrets before they reach your main branch.

### [GitHub Copilot Fusion updates: more availability, benchmarks, and models](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models)
*Nov 17, 2026*

Today, we're expanding GitHub Copilot Fusion with new models, available on more Copilot surfaces, and results on two public Terminal-Bench leaderboards, giving you more ways to use Fusion and compare its performance. Copilot Fusion is coming to more places you use Copilot.

### [MAI Code 2 and MAI Code 2 Flash in GitHub Copilot](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot)
*Nov 17, 2026*

The next generation of Microsoft AI (MAI) coding models has arrived in GitHub Copilot. Introducing MAI Code 2 and MAI Code 2 Flash, two new models that represent a major step forward for the MAI-Code family, expanding from lightweight coding assistance to complex, agentic software engineering.

### [Monitor GitHub Copilot activity through Microsoft Agent 365](https://github.blog/changelog/2026-11-17-monitor-github-copilot-activity-through-microsoft-agent-365)
*Nov 17, 2026*

Enterprises can now stream GitHub Copilot agent activity directly into
Microsoft Agent 365. This lets you bring audit data from across GitHub Copilot clients into Microsoft's agent control plane, where you can review Copilot activity alongside other AI workloads.

### [Building the Agent Host Protocol for sessions that continue across devices](https://github.blog/engineering/engineering-principles/building-the-agent-host-protocol-for-sessions-that-continue-across-devices/)
*Nov 17, 2026*

Models are now good enough to work for hours or even days on their own. You don't have to watch over every thing they do, but you still need to be able to check in, no matter where you are. An agent can't live only inside one application.

### [GitHub Copilot in JetBrains, Ignite releases](https://github.blog/changelog/2026-11-17-github-copilot-in-jetbrains-ignite-releases)
*Nov 17, 2026*

This update brings remote access, on-device voice dictation, and browser use controls to GitHub Copilot for JetBrains. Copilot users in JetBrains IDEs also get context usage shortcuts, historical diffs, simpler follow-up controls, and improvements to chat reliability. Cloud sandbox runs Copilot sessions in an isolated, GitHub-hosted environment instead of on your computer.

### [OpenAI’s GPT-6.2 Astra and GPT-6.2 Sol now available](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available)
*Nov 17, 2026*

OpenAI's GPT-6.2 Astra and GPT-6.2 Sol are now generally available in GitHub Copilot. Both models are designed for agentic coding and code review, with stronger coding judgment than earlier GPT-6 models. In early testing, both caught significantly more real issues in code review than earlier GPT-6 models while using fewer tokens.
